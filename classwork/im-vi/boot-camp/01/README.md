# Interactive Web Demo: Cursor Tracker with Animation

Welcome learners! This demo is designed to introduce you to interactive web development by combining HTML, CSS, and JavaScript. Here's a breakdown of what you'll learn and experience in this demo:

## Overview
- **HTML (index.html):** Structures the webpage and includes elements like a moving ball and social media icons.
- **CSS (main.css):** Adds styling to make the webpage visually appealing, including dynamic hover effects for interactivity.
- **JavaScript (main.js):** Brings the page to life by enabling real-time effects, such as a red ball following your cursor and shrinking when clicked.

## Core Features
1. **Cursor Animation:** Move your mouse, and watch as a red ball follows it across the screen.
2. **Click Interaction:** Clicking the ball triggers a shrinking and color-changing animation.
3. **Stylish Layout:** Includes a centered content block, styled social media links, and responsive design elements.
4. **Resource Practice:** Prepares you to work with images, stylesheets, and external scripts.

## Learning Outcomes
By exploring this project, you'll:
1. Understand how HTML forms the base structure of a webpage.
2. Enhance your CSS knowledge, including transitions and responsiveness.
3. Practice JavaScript to create dynamic, event-driven features.
4. Learn how to integrate images and assets consistently in a project.

Happy coding! Let this serve as both a challenge and a playground as you expand your front-end development skills.
